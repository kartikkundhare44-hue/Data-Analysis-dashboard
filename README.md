# 📊 Student Performance Dashboard

An interactive dashboard created to analyze and visualize student academic performance and identify key factors affecting learning outcomes.

## 🎯 Project Objective

The main objective of this project is to analyze student performance using different academic and demographic factors and present meaningful insights through interactive visualizations.

## 📌 Dashboard Features

- Total number of students
- Average Math, Reading, and Writing scores
- Pass rate and average reading score
- Student performance distribution
- Performance based on parental education
- Performance based on gender
- School type analysis
- Study group analysis
- Teacher quality analysis
- Motivation level analysis
- Subject-wise average scores
- Top-performing students
- Key performance insights

## 📊 Key Insights

- Students with better preparation tend to achieve higher scores.
- Parental education level shows a relationship with student performance.
- Performance can be compared across different school types and genders.
- Around 12% of students are below average and may require additional academic support.
